STUDYUP 3.0 — автономная PWA-версия

СОДЕРЖИМОЕ
- index.html — интерфейс приложения
- app.js — тесты, профиль, статистика, локальное сохранение
- manifest.json — параметры установки
- sw.js — Service Worker для автономной работы
- icon-192.png и icon-512.png — иконки

ВАЖНО
1. Это PWA, а не нативное приложение из App Store.
2. Для первоначальной установки нужен HTTPS-хостинг и Safari.
3. После первого открытия дождитесь загрузки приложения, затем проверьте его в авиарежиме.
4. Данные хранятся локально в браузерном хранилище iPhone. Не очищайте данные Safari для этого сайта, если не сделали резервную копию.
5. Для переноса прогресса используйте Профиль → Экспортировать резервную копию.

КАК УСТАНОВИТЬ НА IPHONE
1. Разместите все файлы папки на HTTPS-хостинге (например, GitHub Pages или другом статическом хостинге).
2. Откройте адрес сайта именно в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите StudyUp с новой иконки.
5. Откройте приложение при наличии интернета, подождите загрузки, затем включите авиарежим и проверьте работу.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
- Тесты и материалы встроены в приложение; редактор позволяет добавлять свои вопросы.
- Нет облачной синхронизации и аккаунтов.
- При удалении сайта/очистке данных браузера локальные данные могут исчезнуть. Экспортируйте резервную копию.
